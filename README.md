# 산업용 로봇 작업 관제 및 관리 시뮬레이션 시스템

산업용 로봇의 상태와 작업을 화면에서 관리하는 WPF 데스크톱 애플리케이션 프로젝트입니다. 기획 문서에 정의한 화면과 기능을 단계적으로 구현하는 개인 학습·포트폴리오 프로젝트입니다.

## 현재 진행 상태

- WPF 로그인 화면과 공통 헤더 구성
- 로그인 성공 후 메인 화면으로 이동하는 기본 흐름 구성
- `root` / `root`는 현재 화면 확인을 위한 임시 개발용 값이며 실제 인증이나 보안 기능은 구현되어 있지 않습니다.
- 로봇·작업·알람 관리와 Oracle 연동은 기획/향후 구현 범위입니다.

## 다음 구현 순서

- [ ] 공통 헤더 영역을 더블클릭하면 창이 최대화되고, 다시 더블클릭하면 원래 크기로 복원되게 하기
- [ ] 로그인 화면에서 아이디와 비밀번호를 입력한 뒤 Enter를 누르면 로그인 버튼과 같은 동작 실행하기
- [ ] 로그인 성공/실패와 창 이동·최대화 동작 확인하기
- [ ] `MainWindow`의 화면 영역을 `ContentControl`로 분리하고, 대시보드 등 화면을 각각 별도 View로 구성하기
- [ ] 여러 화면에서 함께 쓸 스타일을 공통 리소스로 정리하기
- [ ] 대시보드 화면 구성 마무리하기
- [ ] 로봇 관리와 작업 관리·배정 화면 구현하기
- [ ] 작업 관제 시뮬레이션과 알람 관리 화면 구현하기
- [ ] 작업 및 로봇 상태 이력 조회 화면 구현하기
- [ ] ViewModel 바인딩을 적용하고 Model·Repository를 구성한 뒤 Oracle Database 연동하기

이 목록은 현재 구현 상태를 기준으로 한 진행 순서이며, 각 화면은 기획 문서의 요구사항에 맞춰 단계적으로 구현합니다.

## 기술 스택

- C#
- WPF / XAML
- .NET Framework 4.7.2
- Oracle Database 연동 예정
- MVVM 구조 적용 예정

## 실행 방법

1. Visual Studio에서 `2. SourceCode/RobotMonitoringSystem/RobotMonitoringSystem.csproj`를 엽니다.
2. .NET Framework 4.7.2 개발자 팩이 설치되어 있는지 확인합니다.
3. 솔루션을 빌드한 다음 실행합니다.
4. 현재 로그인 화면 테스트 값은 아이디 `root`, 비밀번호 `root`입니다.

> 임시 로그인 값은 학습용 화면 테스트에만 사용합니다. 실제 서비스나 공개 배포 전에 인증 방식으로 교체해야 합니다.
